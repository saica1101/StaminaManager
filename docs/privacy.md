# プライバシー

Stamina Manager はアプリから自動通信を行いません。アカウント登録、広告、
利用状況の計測、テレメトリ、クラッシュ情報の収集は行わず、ゲーム名、
スタミナ、画像、設定などのデータをアプリから外部へ自動送信しません。

## 外部リンク

About の GitHub／README リンクをユーザーが押した場合だけ、固定された HTTPS の URL を
既定のブラウザーへ渡します。アプリ起動時や About 表示時にページを自動取得せず、
WebView による表示、クリック計測、テレメトリも行いません。ブラウザーで開いたページに
ついては、ブラウザーおよびリンク先のプライバシーポリシーが適用されます。

## 保存するデータ

ゲーム、画像、表示・通知設定は、Windows の `ApplicationData` が提供する
アプリ専用のローカル領域に保存します。データはこの端末内だけで使用します。

- 通知は、登録したゲームの全回復予定を Windows 通知として表示するために
  使用します。
- `StartupTask` は、ユーザーが設定をオンにした場合だけ、Windows ログイン時に
  アプリを起動するために使用します。
- バックアップは、ユーザーが Windows のファイル選択画面で選んだ場所への
  書き出し、または選んだファイルからの復元にだけ使用します。アプリが自動で
  外部の場所へ送信することはありません。

通知や Windows ログイン時起動を許可しない場合も、スタミナの確認とローカル
保存は利用できます。

## アンインストール

アプリをアンインストールすると、`ApplicationData` のローカル領域にある
ゲーム、画像、設定は削除されます。必要なデータは、アンインストール前に
Settings からバックアップを書き出すことをおすすめします。ユーザーが選んだ
場所へ書き出したバックアップは、アプリのアンインストール対象ではありません。
